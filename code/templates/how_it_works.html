Core Components
⛓

Blockchain Distributed Design

BC-based peer distribution

  • Distributes evidence across multiple peer nodes using consensus protocol
  • Each block cryptographically chains to its predecessor via prev_hash
  • Proof-of-work mining ensures block validity before commitment
  • Transparent audit trail eliminates single points of failure
  • Smart contract logic automates chain-of-custody verification
🧬

EEO Key Generation

Enhanced Equilibrium Optimizer

  • Swarm intelligence algorithm modeled on thermodynamic equilibrium
  • Population of N=10 candidate keys evaluated for cryptographic fitness
  • Iterative convergence maximizes Shannon entropy of the output key
  • Each evidence file receives a unique, never-reused secret key
  • Resistant to brute-force attacks via key space maximization
🔐

Multi-Key Homomorphic Encryption

Compute on ciphertext

  • Allows integrity verification without ever decrypting evidence
  • Multiple authorized key holders required for threshold decryption
  • Evidence privacy protected even from cloud infrastructure operator
  • Ciphertext hash stored on-chain; plaintext discarded post-encryption
  • Supports role-based partial key distribution
✅

SBVM Authentication

Secure Block Verification Mechanism

  • Multi-factor identity verification before any evidence access is granted
  • Role-based access control: Admin vs Investigator privilege tiers
  • Session token binding prevents replay and hijack attacks
  • All access events logged with timestamp, IP, and action type
  • Automatic detection of unauthorized modification attempts
